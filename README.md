# Global Humanitarian Crisis & Donation Prioritization System

## Project Overview

The **Global Humanitarian Crisis & Donation Prioritization System** is a Python-based interactive dashboard developed using Streamlit and Fuzzy Logic as part of a Soft Computing project.

The system aims to raise awareness about major humanitarian crises, particularly the situation in Palestine, while exploring how soft computing techniques can support humanitarian decision-making and aid distribution.

Using a fuzzy logic-based prioritization model, the system evaluates humanitarian crises based on factors such as urgency and severity to generate priority rankings. It also provides estimated donation impact to help users understand how financial contributions could support humanitarian relief.

## Key Features

- **Humanitarian Crisis Awareness:** Information and awareness messages about Palestine, Sudan, Democratic Republic of the Congo, and Punjab Floods.
- **Fuzzy Logic-Based Prioritization:** Uses fuzzy logic to assess crisis severity and urgency and determine aid priorities.
- **Donation Impact Estimation:** Estimates the potential impact of donations, including estimated impact per $1,000 contributed.
- **Crisis Ranking:** Compares humanitarian emergencies and presents their relative priority.
- **Interactive Visualizations:** Displays analytical insights through bar charts, pie charts, and radar charts.
- **Geographical Visualization:** Uses Folium to present crisis locations on an interactive map.
- **Results Export:** Allows users to export analysis results.

## Technologies Used

- Python
- Streamlit
- Fuzzy Logic / Soft Computing
- Folium
- Data Visualization Libraries

## Project Objective

The primary objective is to demonstrate how soft computing, particularly fuzzy logic, can be applied to real-world humanitarian challenges. By transforming crisis-related indicators into interpretable priority scores, the system provides an interactive way to understand humanitarian needs and explore more informed approaches to aid prioritization.
